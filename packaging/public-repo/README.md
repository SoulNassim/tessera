# Tessera Studio

![Tess, the studio's art director, with a row of game assets](https://soulnassim.github.io/tessera/landing/banner.jpg)

Your game's art department. Describe an asset, and Tess, the studio's art director, makes it: 2D art, pixel sprites, 3D models, rigs, animations and sound. Your coding agent then copies the results into your game.

**Website and downloads:** https://soulnassim.github.io/tessera/

This repository hosts the website and the [releases](https://github.com/SoulNassim/tessera/releases): the Windows installer, the macOS disk image, and a Python wheel for `uv tool install`. It is updated automatically on each release, so please don't send pull requests here. Report bugs and ideas in [Issues](https://github.com/SoulNassim/tessera/issues).
